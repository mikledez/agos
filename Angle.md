# Sprint Biomechanics Reference

## Overview

This document provides reference ranges for lower-limb joint angles during
three phases of sprinting: touchdown, mid-stance, and toe-off.

The measurements are divided into:
1. Swing leg
2. Stance leg

All angles are measured in degrees.

---

# Swing Leg

## Touchdown

### Hip
Reference range: 157–168°

### Knee
Reference range: 39–49°

### Ankle
Reference range: 116–130°

### Thigh
Reference range: 7–28°
